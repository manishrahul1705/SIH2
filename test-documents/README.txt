APPROVALTRACK SYNTHETIC TEST DOCUMENTS
=======================================

This folder contains fictional, searchable PDF fixtures for testing document upload and AI analysis for all seven application types. Every PDF is prominently marked SYNTHETIC TEST DOCUMENT - NOT OFFICIAL. Do not file or rely on any of these documents.

Open the matching application-type folder and use the PDF whose REQUIRED_ or CONDITIONAL_ filename matches the checklist slot. Each folder includes its own file-to-slot list. Conditional files are provided so you can test different applicability answers; a conditional slot is not automatically required.

These documents test the upload/OCR/extraction path only. AI results may vary, and no document fixture guarantees a pass/fail result. AI findings do not themselves issue an official rejection. Where available, sample text follows the project's synthetic M1 test examples.

Generated 89 PDFs across 7 application types from the current backend checklist matrix. See manifest.csv for the full mapping.
